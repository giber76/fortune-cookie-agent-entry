`/output/entry.txt`.

The fortune: "Your lucky numbers are 400, 403, and 429 — you will meet them
all before lunch." A classic fortune-slip opening with an agent's own luck:
the HTTP error codes every agent meets sooner or later.

Run with Node 22: `node main.ts`. No network, no dependencies.
